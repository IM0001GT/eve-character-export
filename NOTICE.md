# Notice

## Purpose

This kit exports **your own** EVE Online character data via official ESI for
personal backup and private use on your computer.

## Not included

- SSO client IDs or secrets  
- Refresh / access tokens  
- Character export data  

You must create your own application on the
[EVE Developers Portal](https://developers.eveonline.com/).
